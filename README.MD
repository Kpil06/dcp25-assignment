# Description of the project
The project is divided into three parts:
1.	Importing ABC files from the provided abc_books folder.
2.	Storing parsed tune information inside tunes.db.
3.	Analysing and visualising the tune metadata using SQL, Pandas and Matplotlib

Tune metadata extracted includes:
Tune index (X:)
Title (T:)
Tune type (R: — e.g., jig, reel, air)
Meter (M:)
Key (K:)
The full raw ABC text

The final result is a complete music database and a set of tools for querying and plotting the data.
# Instructions for use

1:Install required python packeges:

	matplotlib


2:Import all ABC files into SQLite

	Run:
	python starter_code.py in your terminal

	This scans the abc_books/directories, parse every .abc file and inserts all tunes into tunes.db

3: Run Analysis functions

Inside a Python interpreter:
	import analysis

	analysis.tunes_by_key()
	analysis.tunes_by_type()
	analysis.tunes_per_book()

4: Generate visualisations
	import visuals

	visuals.plot_tunes_per_book()
	visuals.plot_tunes_by_key()
